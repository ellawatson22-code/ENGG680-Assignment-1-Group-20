# Assignment 1 ENGG 680, Group 20
## Introduction to Assignment 1
Assignment 1 provides students with the necessary skills to learning python and programming for the eventual use of applying it to machine learning. This assignment has been split up into 3 different parts, part 1 of the assignment focused on python fundamentals, part 2 focused on Pandas and Matplotlib, and finally part 3 focused on linear least squares estimation. Throughout these sections of the assignment, we were required to utilize concepts learned in class to come up with solutions for various problems in order to effectively complete the assignment. 
## Part 1: Python Fundamentals, Loops and Indexing in Python
Most of the questions provided in part one required us to use python to create various text grids such as diagonal entry, block diagonal, block offdiagonal, etc. We were also required to use specific techniques in order to create the correct output. Such techniques include nested for loops and list comprehension. The necessary libraries used for this section include math. We focused on first learning how to create nested for loops for printing a simple diagonal grid. Then, for creating more of the text grids using nested for loops, we used if, elif (else if), and else statements in order to construct the proper grid. Throughout this process, we learned the importance in differences between the outer loop and inner loop, how to use conditional syntax to generate the desired output, and similarly how to apply these concepts to list comprehension. Finally, we also learned how to use nested for loops to generate grids that were both based on square numbers (which required us to import math) as well as grids that contain blocks of certain dimension.
This allowed us to explore new ways of using python fundamentals to create the same output, for example creating the same text grid pattern using nested for loops and list comprehension. Additionally, group members were able to collaborate and come up with ideas to create the same output, and further provided the entire group with an in depth understanding of nested for loops, indexing, and other python fundamentals.
## Part 2: Pandas and Matplotlib
Part 2 introduced us to using Pandas and Matplotlib for analyzing a dataset as well as various functions associated with pandas and generating plots. The dataset required for this section includes the following files: courses.csv, enrollments.csv, students.csv, and teachers.csv, these files are linked together through shared key values. This dataset contains information on various courses, the students enrolled, the teachers who teach the specific courses, letter grades, attendance, and more. The necessary libraries required for this section include matplotlib and pandas. First, we learned how to load the the tables after downloading them to google drive. Then, we performed a variety of Pandas functions in order to isolate the answers to various questions, including determining the student with the highest grade in english, number of students in each course, and more. These questions introduced us to important Pandas functions such as merge and groupby which allows for effective analysis of databases that can be applied to projects down the road. Finally, we created various scatter plots based on this dataset such as students grades vs. attendance, which we then created subplots that were restricted to each individual course. Finally, we generated a report card using matplotlib in order to evaluate each students performance in each course.
This part of the assignment was crucial in teaching us how to create plots and subplots based on a dataset. Similarly, this section of the assignment also allowed us to learn crucial Pandas functions in order to analyze our data and extract answers from the data in a quick and efficient manner.
## Part 3: Linear Least Squares Estimation
Part 3 was focused on least squares estimation, in which we are given observations about a function and the unknown states, which is the coefficients used for curve fitting. This section provided an introduction into curve fitting and LSE, as we were required to walk through the process of curve fitting step by step (based on what we learned in lecture in class) in order to successfully plot true and noisy observations together. In order to do this section, we were required to import all necessary libraries, this includes numpy, matplotlib, and pandas.
